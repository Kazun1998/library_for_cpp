## Outline

長さ $n$ の列 $S$ に対して, $S$ の各位置 (要素の上, および隣り合う $2$ 要素の間) を中心とする最長の回文部分文字列の長さを, まとめて $O(n)$ 時間で求める (Manacher 法).

回文部分文字列の中に別の回文が入れ子になっていることを利用して, すでに求めた結果を鏡写しにして再利用するのが基本戦略である. 理論では, まず各要素を中心とする奇数長の回文だけを考え, 偶数長の回文は列に区切りの文字を挟むことで奇数長の場合に帰着する.

## Define

* 列/文字列に関する記法 (空列 $\emptyset$, 結合 $\oplus$, 長さ $\lvert \alpha \rvert$ など) と回文は, [列/文字列](/String.html) に従う.
* $X$ をアルファベット, $S = (S_1, S_2, \dots, S_n) \in X^\ast$ とする. $n = \lvert S \rvert$ である. 以下の理論の説明では, 添字は $1$ から始める (実装では $0$ から始めることに注意. 対応は命題 6 の後で述べる).
* $1 \leq l \leq r + 1 \leq n + 1$ を満たす整数 $l, r$ に対して, $S$ の部分文字列 $(S_l, S_{l+1}, \dots, S_r)$ を $S[l, r]$ と書く. $l = r + 1$ のときは空列である.
* $S[l, r]$ が回文であることは, 任意の $0 \leq j \leq r - l$ に対して $S_{l+j} = S_{r-j}$ であることと同値である.

## Theory

### 理論付け

はじめに, 各要素を中心とする奇数長の回文だけを考える.

<div class="definition" markdown="1">

定義 1
---

$1 \leq i \leq n$ とする. 正の整数 $k$ が次を満たすとき, $k$ は $i$ に対して許容であるという.

* $1 \leq i - k + 1$ かつ $i + k - 1 \leq n$.
* 任意の $0 \leq j < k$ に対して $S_{i-j} = S_{i+j}$.

つまり, $S[i-k+1, i+k-1]$ が (長さ $2k - 1$ の) 回文であることである. $i$ に対して許容な $k$ の最大値を $\rho(i)$ と書く.

</div>

$k = 1$ は常に許容なので, $\rho(i)$ は well-defined である. $\rho(i)$ は, 第 $i$ 要素を中心とする最長の奇数長の回文の半径 (中心を含む) であり, その長さは $2 \rho(i) - 1$ である. 目標は, $\rho(1), \rho(2), \dots, \rho(n)$ をすべて求めることである.

<div class="proposition" markdown="1">

命題 2
---

$k \geq 2$ が $i$ に対して許容ならば, $k - 1$ も許容である. したがって, $k$ が $i$ に対して許容であることと, $1 \leq k \leq \rho(i)$ であることは同値である.

</div>

<div class="proof" markdown="1">

証明
---

許容の条件を $k - 1$ について確かめればよい. 範囲の条件は $k$ のときより緩く, 等式の条件は $j$ の範囲が狭くなるだけである. 後半は, 前半を繰り返し用いればよい.
</div>

命題 2 より, ある $k_0 \leq \rho(i)$ が分かっているならば, $k_0$ から $1$ ずつ増やして許容でなくなる直前の値を取れば $\rho(i)$ が得られる. すなわち, 区間を両端 $1$ ずつ広げながら, 両端の要素が存在して等しいかを確かめればよい. 問題は, 出発点 $k_0$ を比較なしで十分大きく取れるかである. それを与えるのが次の命題である.

<div class="proposition" markdown="1">

命題 3
---

$1 \leq c \leq n$ とし, $r_0 = c + \rho(c) - 1$, $L = c - \rho(c) + 1$ とおく ($L + r_0 = 2c$ である). $c < i \leq r_0$ を満たす $i$ に対して, $i' = 2c - i$, $B = r_0 - i + 1$ とおく. このとき, 以下が成り立つ.

* (a) $\rho(i) \geq \min(\rho(i'), B)$.
* (b) $\rho(i') < B$ ならば, $\rho(i) = \rho(i')$.

</div>

<div class="proof" markdown="1">

証明
---

$L \leq i' < c < i \leq r_0$ であり, $L \geq 1$ かつ $r_0 \leq n$ である. また, 区間 $S[L, r_0]$ は回文なので, 任意の $x \in [L, r_0]$ に対して $S_x = S_{2c-x} ~ (\dagger)$ である.

次に, $0 \leq j < B$ とする. このとき $i + j \leq i + B - 1 = r_0$ であり, $i - j \geq i - B + 1 = 2i - r_0 > 2c - r_0 = L$ である. したがって, $i - j$ と $i + j$ は $[L, r_0]$ に含まれ, $(\dagger)$ より

$$ S_{i+j} = S_{2c - i - j} = S_{i' - j}, \quad S_{i-j} = S_{2c - i + j} = S_{i' + j} \quad (0 \leq j < B) \quad \cdots (\ddagger) $$

である. ここで, $i' \pm j = 2c - (i \mp j)$ も $[L, r_0]$ に含まれることに注意する.

**(a)**: $m = \min(\rho(i'), B)$ とする. $0 \leq j < m$ ならば, 上の議論から $i - j \geq 1$, $i + j \leq n$ であり, $j < \rho(i')$ より $S_{i'-j} = S_{i'+j}$ なので, $(\ddagger)$ より $S_{i+j} = S_{i-j}$ である. よって $m$ は $i$ に対して許容であり, $\rho(i) \geq m$ である.

**(b)**: $t = \rho(i') < B$ とする. このとき $m = t$ なので, (a) より $\rho(i) \geq t$ である. $\rho(i) > t$ と仮定すると, 命題 2 より $t + 1$ は $i$ に対して許容なので, $S_{i-t} = S_{i+t}$ である. $t < B$ なので $(\ddagger)$ より $S_{i'-t} = S_{i+t} = S_{i-t} = S_{i'+t}$ であり, $i' \pm t \in [L, r_0] \subset [1, n]$ である. すると $t + 1$ は $i'$ に対して許容となり, $\rho(i') = t$ に矛盾する. よって $\rho(i) = t = \rho(i')$ である.
</div>

### アルゴリズム

$i = 1, 2, \dots, n$ の順に $\rho(i)$ を決める. その際, 次の $2$ つの値を持つ.

* $c$: これまでに処理した $i$ のうち, $i + \rho(i) - 1$ が最大のもの.
* $r_0 = c + \rho(c) - 1$ (初期値は $r_0 = 0$ で, $c$ はまだない).

各 $i$ について, まず出発点 $k_0$ を次で決める.

* $i > r_0$ のとき: $k_0 = 1$.
* $i \leq r_0$ のとき: $i' = 2c - i$ として, $k_0 = \min(\rho(i'), r_0 - i + 1)$.

次に $k = k_0$ から始めて, $i - k \geq 1$, $i + k \leq n$, $S_{i-k} = S_{i+k}$ のすべてが成り立つ限り $k$ を $1$ ずつ増やし, 止まったときの $k$ を $\rho(i)$ とする. 最後に, $i + \rho(i) - 1 > r_0$ ならば, $c := i$, $r_0 := i + \rho(i) - 1$ と更新する.

<div class="proposition" markdown="1">

命題 4
---

上のアルゴリズムは $\rho(1), \dots, \rho(n)$ を正しく求め, その計算量は $O(n)$ である. ただし, 要素同士の比較は $O(1)$ 時間でできるとする.

</div>

<div class="proof" markdown="1">

証明
---

**正当性**: $k_0$ が $i$ に対して許容であることを示せば, 命題 2 より, 広げる操作は止まったときに $\rho(i)$ を与える.

* $i > r_0$ のとき, $k_0 = 1$ は常に許容である.
* $i \leq r_0$ のとき, $c$ は $i$ より前に処理した値なので $c < i$ であり, $i' < c$ より $\rho(i')$ はすでに求まっている. $c$ は $r_0 = c + \rho(c) - 1$ を満たすので, 命題 3 の仮定を満たす. よって命題 3 (a) より, $k_0 = \min(\rho(i'), B)$ は許容である.

**計算量**: 広げる回数の総和を評価する. $i$ で広げる前の右端を $e_0 = i + k_0 - 1$, 広げた後の右端を $e = i + \rho(i) - 1$ とすると, 広げる回数は $e - e_0$ である. 処理前の $r_0$ に対して, 次が成り立つ.

* $i > r_0$ のとき, $e_0 = i > r_0$.
* $i \leq r_0$ かつ $\rho(i') \geq r_0 - i + 1$ のとき, $e_0 = r_0$.
* $i \leq r_0$ かつ $\rho(i') < r_0 - i + 1$ のとき, 命題 3 (b) より $\rho(i) = \rho(i') = k_0$ なので, 広げる回数は $0$.

したがって, $1$ 回以上広げるときは $e > e_0 \geq r_0$ であり, 広げる回数は $e - e_0 \leq e - r_0$ で, 処理後に $r_0$ は $e$ に更新される. $r_0$ は $0$ から単調に増加して $n$ 以下であるから, 広げる回数の総和は $n$ 以下である. 各 $i$ について, 広げる操作が止まる比較も高々 $1$ 回であり, それ以外の処理は $O(1)$ 時間であるから, 全体で $O(n)$ 時間である.
</div>

偶数長の回文は, 奇数長の回文の中心を要素の上に取れない. そこで, $X$ に含まれない文字 $\\#$ を, $S$ の各要素の間と両端に挟んだ列を考える.

<div class="definition" markdown="1">

定義 5
---

$\\# \notin X$ とする. 長さ $2n + 1$ の列 $T = (T_1, \dots, T_{2n+1})$ を, $1 \leq i \leq n$ に対して $T_{2i} = S_i$, $1 \leq i \leq n + 1$ に対して $T_{2i-1} = \\#$ で定める. すなわち

$$ T = (\#, S_1, \#, S_2, \#, \dots, \#, S_n, \#) $$

である. $T$ に対する定義 1 の $\rho$ を, $S$ のものと区別して $\rho_T$ と書く.

</div>

<div class="proposition" markdown="1">

命題 6
---

$2 \leq q \leq 2n$ とする. $l + r = q$, $1 \leq l$, $r \leq n$, $l \leq r + 1$ を満たす $S[l, r]$ のうち回文であるものの長さの最大値は, $\rho_T(q) - 1$ である.

</div>

<div class="proof" markdown="1">

証明
---

$l + r = q$, $1 \leq l$, $r \leq n$, $l \leq r + 1$ とする. $T[2l - 1, 2r + 1] = (\\#, S_l, \\#, S_{l+1}, \dots, S_r, \\#)$ は $T$ の区間であり, 中心は $(2l - 1 + 2r + 1) / 2 = q$ で, 対応する半径は $k = r - l + 2$ である. この区間の位置 $2(l + j)$ (要素 $S_{l+j}$) の鏡像は $2l - 1 + 2r + 1 - 2(l + j) = 2(r - j)$ であり, 奇数の位置は鏡像も奇数の位置なので $\\#$ 同士が対応する. したがって,

$$ S[l, r] \text{ が回文} \iff k = r - l + 2 \text{ は } q \text{ に対して許容} $$

である (許容は定義 1 を $T$ に適用したもの). この $k$ に対して $S[l, r]$ の長さは $k - 1$ である.

よって, $S[l, r]$ の長さの最大値 $\leq \rho_T(q) - 1$ は従う. 逆向きを示すため, $k = \rho_T(q)$ とおき, 区間 $T[q - k + 1, q + k - 1]$ の両端が奇数の位置 (つまり $\\#$) であることを示す. 両端が偶数の位置だとすると, $2 \leq q - k + 1$ かつ $q + k - 1 \leq 2n$ なので $q - k \geq 1$, $q + k \leq 2n + 1$ であり, この $2$ 点は奇数の位置なので $T_{q-k} = T_{q+k} = \\#$ である. すると $k + 1$ も許容となり $k$ の最大性に矛盾する. したがって, 両端は奇数の位置で, ある $l, r$ を用いて $[2l - 1, 2r + 1]$ と書ける. これは $1 \leq l$, $r \leq n$, $l + r = q$ を満たし, 上の同値より $S[l, r]$ は回文で長さ $k - 1$ である.
</div>

命題 6 より, $T$ に対して (奇数長だけを考える) アルゴリズムを実行すれば, $S$ の回文の中心 (要素の上と隣り合う $2$ 要素の間) すべてについて最長の回文の長さが得られる. $T$ の長さは $2n + 1$ なので, 計算量は $O(n)$ である. 実装の配列 `R` (添字は $0$ 始まり, 長さ $2n - 1$) とは, `R[q]` $= \rho_T(q + 2) - 1$ ($0 \leq q \leq 2n - 2$) という関係にある. 特に, `R[q]` の $q$ が偶数ならば $S$ の第 $q / 2$ 要素 ($0$ 始まり) を中心とする奇数長の回文, $q$ が奇数ならば第 $(q - 1) / 2$ 要素と第 $(q + 1) / 2$ 要素 ($0$ 始まり) の間を中心とする偶数長の回文である.

実装では $T$ を実際には作らず, 奇数長と偶数長を別々に同じ手順で計算し, 最後に併せる. 添字を $0$ 始まりにして, 第 $i$ 要素を中心とする奇数長の回文の半径 $\mathrm{odd}[i] = (\mathtt{R}[2i] + 1) / 2$ と, 第 $(i-1)$, $i$ 要素の間を中心とする偶数長の回文の半径 $\mathrm{even}[i] = \mathtt{R}[2i - 1] / 2$ を求め, $\mathtt{R}[2i] = 2 \mathrm{odd}[i] - 1$, $\mathtt{R}[2i - 1] = 2 \mathrm{even}[i]$ とする.

* $S$ の最長の回文部分文字列の長さは, `R` の最大値である.
* 同じ中心をもつ回文の両端を取り除いても回文なので, `R[q]` $> 0$ のとき, その中心をもつ空でない回文部分文字列は $\lceil$ `R[q]` $/ 2 \rceil$ 個ある. よって, 位置の違いを区別した回文部分文字列 (空でない) の個数は $\displaystyle \sum_{q=0}^{2n-2} \left\lceil \frac{\mathtt{R}[q]}{2} \right\rceil$ である.

### 具体例

$S = $ `abaa` ($n = 4$, $S_1 = $ `a`, $S_2 = $ `b`, $S_3 = $ `a`, $S_4 = $ `a`) のとき, $T = $ `#a#b#a#a#` である.

|$q$|$T_q$|$\rho_T(q)$|$S$ での中心|最長の回文|`R` の添字|`R` の値 ($\rho_T(q) - 1$)|
|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
|1|`#`|1|(両端)|||
|2|`a`|2|第 1 要素|`a`|0|1|
|3|`#`|1|第 1, 2 要素の間|(空)|1|0|
|4|`b`|4|第 2 要素|`aba`|2|3|
|5|`#`|1|第 2, 3 要素の間|(空)|3|0|
|6|`a`|2|第 3 要素|`a`|4|1|
|7|`#`|3|第 3, 4 要素の間|`aa`|5|2|
|8|`a`|2|第 4 要素|`a`|6|1|
|9|`#`|1|(両端)|||

実装の配列は `R` $= (1, 0, 3, 0, 1, 2, 1)$ である. 回文部分文字列の個数は $1 + 0 + 2 + 0 + 1 + 1 + 1 = 6$ であり, `a` (第 1 要素), `b`, `aba`, `a` (第 3 要素), `aa`, `a` (第 4 要素) に一致する.

## Contents

以下, $n$ を列の長さとする.

### Manacher

```cpp
template<typename T>
vector<int> Manacher(const vector<T> &data)
```

* $T$ 上の列 `data` に対して, 長さ $2n - 1$ の列 `R` を求める ($n = $ `data.size()`). ただし, $n = 0$ のときは空列を返す. 実装では添字は $0$ 始まりであり, 理論での $\rho_T$ (定義 5) を用いて `R[q]` $= \rho_T(q + 2) - 1$ である.
  * `R[2i]`: `data[i]` (第 $i$ 要素, $0$ 始まり)を中心とする最長の (奇数長の) 回文の長さ.
  * `R[2i - 1]`: `data[i-1]` と `data[i]` の間を中心とする最長の (偶数長の) 回文の長さ. 回文がなければ $0$.
* **制約**
  * $T$ は `==` で比較できる.
* **計算量** : $O(n)$ 時間 (命題 4, 命題 6).

```cpp
vector<int> Manacher(const string &str)
```

* 文字列 `str` に対して, 上記と同様の列を求める ($n = $ `str.size()`).
* **計算量** : $O(n)$ 時間.
