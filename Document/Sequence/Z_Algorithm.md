## Outline

Z Algorithm を用いて, 長さ $n$ の列 $S$ の各 $i = 0, 1, \dots, n-1$ に対する以下を合計で $O\left(n \right)$ 時間で求める.

* $S$ と $S[i:]$ ($S$ の第 $i$ 要素目以降からなる列) の最長共通接頭辞の長さ

## Define

* 列 $T$ が列 $S$ の接頭辞であるとは, 以下を満たすことである.
  * $\lvert T \rvert \leq \lvert S \rvert$.
  * $S_i = T_i \quad (i = 0, 1, \dots, \lvert T \rvert - 1)$.
* 列 $U$ が列 $S, T$ の接頭辞であるとき, $U$ は $S, T$ の共通接頭辞であるという.
* 列 $S, T$ の共通接頭辞のうち, 長さが最大である列がただ一つ存在する. その列を $S, T$ の最長共通接頭辞という.

## Theory

以下のように記号を定義する.

* 列 $S$ の長さを $n$ とする.
* $Z[i]$ を $S$ と $S[i:]$ の最長共通接頭辞の長さとする. 特に $Z[0] = n$ である.

### アルゴリズム

現在の位置 $i$ と, $i$ から始まる一致の長さの下界 $j$ を持ちながら, $i$ を左から右へ進める. ただし, $S[0:j] = S[i:i+j]$ は既に確認済みである (初期状態は $i = 1, j = 0$).

1. $S_j = S_{i+j}$ である限り $j$ を増やす. 終了時の $j$ が $Z[i]$ となる.
2. $j = 0$ ならば $i$ を $1$ 進めて 1. に戻る.
3. $Z[i] = j$ を確定する. 続いて $k = 1, 2, \dots$ に対し, $Z[k] < j - k$ かつ $i + k < n$ を満たす間, $Z[i+k] = Z[k]$ とする.
4. 上記 3. が止まった時点の $k$ について, $i \gets i + k$, $j \gets j - k$ として 1. に戻る.

$i \geq n$ となったら終了する.

### 正当性

$S[i:i+j] = S[0:j]$ かつ $Z[i] = j$ であるとき, $0 < k < j$ に対して $S[i+k:i+j] = S[k:j]$ である.

**証明**

#### $Z[k] < j - k$ のとき

$S[k:]$ と $S$ は $Z[k]$ 文字目で初めて異なり, その位置 $k + Z[k]$ は $j$ 未満なので $S[i:i+j]$ の内側にある.

故に, $S[i+k:]$ と $S$ も同じ位置で初めて異なるから, $Z[i+k] = Z[k]$ である.

#### $Z[k] \geq j - k$ のとき

$S[i+k:i+j]$ が $S[0:j-k]$ と一致することしか分からないので, $Z[i+k] \geq j - k$ である.

故に, $j \gets j - k$ として一致の延長から再開すればよい. $k = j$ の場合は $j \gets 0$ となり, 最初から比べ直すことに相当する.

### 計算量

$r = i + j$ (一致が確認済みの右端) を考える.

* 手順 4. では $r$ は変化しない.
* 手順 1. で比較に成功するたびに $r$ が $1$ 増える. $r \leq n$ であり $r$ は減らないので, 比較の成功は全体で高々 $n$ 回.
* 手順 1. を実行するたびに, $i$ は $1$ 以上増える ($j = 0$ なら $+1$, そうでなければ $+k \geq 1$). $i < n$ なので, 手順 1. の実行回数は高々 $n$ 回. 比較の失敗は 1 回の実行につき高々 $1$ 回なので, 全体で高々 $n$ 回.
* 手順 3. の反復回数は $i$ の増加量 $k$ に等しいので, 全体で高々 $n$ 回.

以上より, 全体で $O(n)$ 時間である.

## Contents

```cpp
template<typename T>
vector<int> Z_Algorithm(const vector<T> &data)
```

* $T$ 上の列 `data` (長さ $n$) に関して, 各 $i = 0, 1, \dots, n-1$ に対し, `data` と `data` の第 $i$ 要素目以降からなる列の最長共通接頭辞の長さを求める.
* 要素同士の比較には `==` を用いるため, $T$ には `operator==` が必要である.
* **制約**: $n \geq 1$.
* **返り値**
  * 長さ $n$ の `vector<int>` 型の列 $Z$.
  * $Z[i]$ は `data` と `data` の第 $i$ 要素目以降の最長共通接頭辞の長さ. 特に $Z[0] = n$.
* **計算量**: $O(n)$ 時間.

```cpp
vector<int> Z_Algorithm(const string &str)
```

* 文字列 `str` に対して, 上記と同様の列を求める.
* **制約**: $\lvert \mathrm{str} \rvert \geq 1$.
* **返り値**: 上記と同様の列 $Z$.
* **計算量**: $O(\lvert \mathrm{str} \rvert)$ 時間.
