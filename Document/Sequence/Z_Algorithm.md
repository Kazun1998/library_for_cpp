## Outline

Z Algorithm を用いて, 長さ $n$ の列 $S$ の各 $i = 0, 1, \dots, n-1$ に対する以下の値を合計で $O\left(n \right)$ 時間で求める.

* $S$ と $S[i:)$ ($S$ の第 $i$ 要素目以降からなる列) の最長共通接頭辞の長さ

## Define

<div class="definition" markdown="1">

定義 1
---

* $T$ が $S$ の接頭辞であるとは, 以下を満たすことである.
  * $\lvert T \rvert \leq \lvert S \rvert$.
  * $S_i = T_i \quad (i = 0, 1, \dots, \lvert T \rvert - 1)$.
* 列 $U$ が列 $S, T$ の接頭辞であるとき, $U$ は $S, T$ の共通接頭辞であるという.

</div>

<div class="definition" markdown="1">

定義 2
---

* 列 $S$ と $0 \leq l \leq r \leq n$ に対し, $S[l:r)$ を $S_l, S_{l+1}, \dots, S_{r-1}$ からなる列とする (第 $r$ 要素は含まない). また $S[l:) := S[l:n)$ とする.
* 列 $S, T$ の共通接頭辞のうち, 長さが最大のものの長さを $\mathrm{lcp}(S, T)$ で表す.
* 長さ $n$ の列 $S$ に対し, $Z_i := \mathrm{lcp}(S, S[i:)) \quad (i = 0, 1, \dots, n-1)$ とおく.
  * 空列は共通接頭辞なので $Z_i \geq 0$ であり, 共通接頭辞は $S[i:)$ の接頭辞なので $Z_i \leq n - i$ である. 特に $Z_0 = n$ である.
  * 定義 1 より, $0 \leq m \leq n - i$ に対し, $S[0:m)$ が $S$ と $S[i:)$ の共通接頭辞であることと, $S_t = S_{i+t} \ (t = 0, 1, \dots, m-1)$ であることは同値である. よって $Z_i$ は, この条件を満たす最大の $m$ である.
* $0 \leq l < r \leq n$ が $S[l:r) = S[0:r-l)$ を満たすとき, 区間 $[l, r)$ を $S$ の **Z-box** という.

</div>

## Theory

<div class="proposition" markdown="1">

命題 1
---

$[l, r)$ を $S$ の Z-box とする. このとき, $l < i < r$ を満たす任意の $i$ に対し, $k = i - l$ とおくと,

$$ S[i:r) = S[k:r-l) $$

が成り立つ. 特に, $S[i:r)$ と $S[k:r-l)$ の長さはともに $r - i$ である.

</div>

<div class="proof" markdown="1">

証明
---

$S[i:r)$ の長さは $r - i$ であり, $S[k:r-l)$ の長さは $(r - l) - (i - l) = r - i$ であるから, 長さは等しい.

$t = 0, 1, \dots, r-i-1$ を任意にとる. $s = k + t$ とおくと,

$$ s = (i - l) + t < (i - l) + (r - i) = r - l $$

である. Z-box の定義 $S[l:r) = S[0:r-l)$ より, $0 \leq s < r - l$ に対して $S_{l+s} = S_s$ が成り立つ. ここで $l + s = l + k + t = i + t$ であるから,

$$ S_{i+t} = S_{l+s} = S_s = S_{k+t} $$

を得る. これが $t = 0, 1, \dots, r-i-1$ で成り立つので, $S[i:r) = S[k:r-l)$ である.

</div>

この命題により, Z-box $[l, r)$ の内部の位置 $i$ では, $[i, r)$ の範囲における $S[i:)$ と $S$ の比較を, $S[k:)$ と $S$ の比較 (すなわち既に求めた $Z_k$) に置き換えられる.

<div class="proposition" markdown="1">

命題 2
---

$[l, r)$ を $S$ の Z-box とする. $l < i < r$ を満たす $i$ に対し $k = i - l$ とおく. このとき, 以下が成り立つ.

1. $Z_k < r - i$ ならば, $Z_i = Z_k$.
2. $Z_k \geq r - i$ ならば, $Z_i \geq r - i$.

</div>

<div class="proof" markdown="1">

証明
---

$d = r - i$ とおく. $i > l$ より $k \geq 1$ であり, $r \leq n$ より $d \leq n - i$ である. 命題 1 より,

$$ S_{i+t} = S_{k+t} \quad (t = 0, 1, \dots, d-1) \tag{$*$} $$

が成り立つ. また, 定義 2 より, 整数 $m$ ($0 \leq m \leq n-i$) について「$S_t = S_{i+t} \ (0 \leq t < m)$」は, $m$ を小さくしても成り立ち続ける. よって $Z_i \geq m$ であることは, この条件が $m$ で成り立つことと同値である ($Z_k$ についても同様).

**1.** $m = Z_k < d$ とする.

* $Z_i \geq m$ の確認: $t = 0, 1, \dots, m-1$ で, $Z_k = m$ より $S_t = S_{k+t}$ であり, $m < d$ と $(*)$ より $S_{k+t} = S_{i+t}$ である. よって $S_t = S_{i+t}$ である. なお $m < d \leq n - i$ なので $m \leq n - i$ である.
* $Z_i \leq m$ の確認: $Z_i \geq m+1$ と仮定すると, $S_m = S_{i+m}$ である. 一方, $m < d$ と $(*)$ より $S_{i+m} = S_{k+m}$ であるから, $S_m = S_{k+m}$ となる. さらに $k + m < k + d = r - l \leq n$ なので $m + 1 \leq n - k$ であり, $t = 0, 1, \dots, m$ で $S_t = S_{k+t}$ が成り立つ. これは $Z_k \geq m + 1$ を意味し, $Z_k = m$ に矛盾する.

以上より $Z_i = m = Z_k$ である.

**2.** $Z_k \geq d$ とする. 上の注意より, $t = 0, 1, \dots, d-1$ で $S_t = S_{k+t}$ であり, $(*)$ より $S_{k+t} = S_{i+t}$ である. よって $S_t = S_{i+t} \ (0 \leq t < d)$ であり, $d \leq n - i$ なので $Z_i \geq d = r - i$ である.

</div>

実装では, $[i, i+j)$ を Z-box (つまり $l = i,\ r = i + j$) として, 位置 $i + k$ に対してこの命題を用いている.

* (1) の場合は $Z_{i+k} = Z_k$ が確定するので, 前までの計算結果から参照すればよい.
* (2) の場合は $Z_{i+k} \geq j - k$ が保証されるので, 位置 $(i + k)$ からスタートして序盤をスキップしながらでも 値を決定できる.

### アルゴリズムの正当性

長さ $n$ の列 $S$ に対する, 実装のアルゴリズムは以下の通りである. ここで, $A$ は長さ $n$ の配列であり, 最終的に $A_s = Z_s$ となることを示す.

<div class="box" markdown="1">

アルゴリズム
---

入力: 長さ $n$ の列 $S$. 出力: 配列 $A$.

$$
\begin{array}{rl}
1: & A_0 \leftarrow n,\ A_s \leftarrow 0 \quad (s = 1, 2, \dots, n-1) \\
2: & i \leftarrow 1,\ j \leftarrow 0 \\
3: & \mathbf{while}\ i < n\ \mathbf{do} \\
4: & \quad \mathbf{while}\ i + j < n\ \mathbf{and}\ S_j = S_{i+j}\ \mathbf{do} \\
5: & \quad \quad j \leftarrow j + 1 \\
6: & \quad \mathbf{if}\ j = 0\ \mathbf{then} \\
7: & \quad \quad i \leftarrow i + 1 \\
8: & \quad \quad \mathbf{continue} \\
9: & \quad A_i \leftarrow j \\
10: & \quad k \leftarrow 1 \\
11: & \quad \mathbf{while}\ k < n - i\ \mathbf{and}\ k < j - A_k\ \mathbf{do} \\
12: & \quad \quad A_{i+k} \leftarrow A_k \\
13: & \quad \quad k \leftarrow k + 1 \\
14: & \quad i \leftarrow i + k,\ j \leftarrow j - k \\
15: & \mathbf{return}\ A
\end{array}
$$

</div>

以下, 3 行目の $\mathbf{while}$ の本体 (4〜14 行目) の 1 回の実行を**反復**と呼ぶ.

<div class="proposition" markdown="1">

命題 3
---

各反復の開始時点 (3 行目の $i < n$ の判定の直前) で, 以下が成り立つ.

1. $1 \leq i \leq n$ かつ $0 \leq j \leq n - i$.
2. $S[0:j) = S[i:i+j)$.
3. $s = 0, 1, \dots, i-1$ に対し, $A_s = Z_s$.

さらに, 各反復で $i$ は真に増加するため, 3 行目の $\mathbf{while}$ は有限回で終了し, 終了時には全ての $s = 0, 1, \dots, n-1$ に対して $A_s = Z_s$ となる.

</div>

<div class="proof" markdown="1">

証明
---

反復の回数に関する帰納法で示す. 最初の反復の開始時点では $i = 1,\ j = 0$ であり, 1. と 2. は明らかに成り立ち (空列同士は一致する), 3. は $A_0 = n = Z_0$ から成り立つ.

ある反復の開始時点で 1.〜3. が成り立つと仮定し, その反復が終わった後の値を $i', j'$ とおく. このとき $i < n$ である.

**4〜5 行目の終了時に $j = Z_i$ である.**

仮定 2. と 1. より, 整数 $j$ ($0 \leq j \leq n - i$) は「$S_t = S_{i+t} \ (0 \leq t < j)$」を満たす. 4〜5 行目は $i + j < n$ かつ $S_j = S_{i+j}$ の間だけ $j$ を 1 増やすため, この性質と $j \leq n - i$ は実行中も保たれる. 終了時は次のいずれかである.

* $i + j = n$ のとき: $Z_i \leq n - i = j$ であり, $Z_i \geq j$ なので $Z_i = j$.
* $S_j \neq S_{i+j}$ のとき: $j + 1$ では条件が成り立たないので, $Z_i < j + 1$. よって $Z_i = j$.

(定義 2 の注意より, $Z_i \geq m$ であることは, 「$S_t = S_{i+t} \ (0 \leq t < m)$」が成り立つこと, と同値であった.) 以降, $j$ は 4〜5 行目の終了後の値とし, $j = Z_i$ である.

**$j = 0$ の場合 (6〜8 行目).** $A_i$ は初期値の $0$ のままであり, $Z_i = j = 0$ なので $A_i = Z_i$. $i' = i + 1,\ j' = 0$ である. 1.〜3. は容易に確認できる.

**$j \geq 1$ の場合.** 9 行目により $A_i = j = Z_i$ となる. また, $S[i:i+j) = S[0:j)$ かつ $i + j \leq n$ なので, $[i, i+j)$ は $S$ の Z-box である. 以降, 命題 2 を $l = i,\ r = i + j$ として用いる. 11〜13 行目の実行中に成り立つことを順に確認する.

* **$k \leq j$ かつ $k \leq n - i$.** $k$ は $1$ から始まり, 13 行目で増やすのは $k < n - i$ かつ $k < j - A_k \leq j$ のときだけ ($A_k \geq 0$ のため) である. よって $k \leq \min(j, n - i)$.
* **12 行目を実行するときは $k < i$.** $k = i$ のとき, $A_k = A_i = j$ なので $j - A_k = 0$ となり, 11 行目の条件 $k < j - A_k$ は偽である. $k$ は 1 ずつ増えるので, $k = i$ に到達する前に 12 行目が実行されるのは $k < i$ のときだけである.
* **12 行目で書き込む値は正しい.** 12 行目を実行するときの $k$ について, $1 \leq k < i$ なので, 仮定 3. より $A_k = Z_k$ であり, 11 行目の条件から $k < j - Z_k$ すなわち $Z_k < j - k$ である. $0 < k < j$ なので, 位置 $i + k$ に対して命題 2 (1) を用いると $Z_{i+k} = Z_k$ である. よって $A_{i+k} \leftarrow A_k$ は正しい値を書き込む.

11〜13 行目の終了時の $k$ を用いると, $i' = i + k,\ j' = j - k$ である. 上の 2 つ目までの確認から $1 \leq k \leq \min(j, n - i)$ なので, 1. は成り立つ ($i' \geq i + 1,\ i' \leq n,\ j' \geq 0,\ i' + j' = i + j \leq n$). 特に, $i$ は真に増加している.

3. が成り立つことを示す. $s < i$ では仮定による. $s = i$ では $A_i = Z_i$ を示した. $s = i + t \ (1 \leq t < k)$ では, 12 行目で書き込まれた $A_{i+t}$ が $Z_{i+t}$ に等しいことを示した. 以上で $s < i + k = i'$ に対して成り立つ.

2. が成り立つことを示す. 11〜13 行目の終了条件は $k = n - i$ または $k \geq j - A_k$ である.

* $k = j$ のとき: $j' = 0$ であり, 空列同士は一致する.
* $k < j$ のとき: 位置 $i + k$ は Z-box $[i, i+j)$ の内部にある. このとき, $Z_k \geq j - k$ が成り立つことを示す. $k = n - i$ ならば $j \leq n - i = k$ に反するので, 終了条件は $k \geq j - A_k$ である. $k < i$ ならば $A_k = Z_k$ であり, $k = i$ ならば $Z_k = Z_i = j \geq j - k$ である. ($k > i$ にはならない.) いずれの場合も $Z_k \geq j - k$ であるから, 命題 2 (2) より $Z_{i+k} \geq j - k$, すなわち $Z_{i'} \geq j'$ である. 定義 2 の注意より, $S[0:j') = S[i':i'+j')$ である.

以上で, 反復後も 1.〜3. が成り立つ.

最後に, 各反復で $i$ は真に増加し $i \leq n$ なので 3 行目の $\mathbf{while}$ は有限回で終了し, 終了時は $i = n$ である. このとき 3. より全ての $s = 0, 1, \dots, n-1$ に対して $A_s = Z_s$ である.

</div>

<div class="proposition" markdown="1">

命題 4
---

列の要素同士の比較 $S_j = S_{i+j}$ を $O(1)$ 時間で行えるとき, 上記のアルゴリズムの計算量は $O(n)$ 時間である.

</div>

<div class="proof" markdown="1">

証明
---

1 行目は $O(n)$ 時間である. 以降, 3 行目の $\mathbf{while}$ について, 反復の回数と, 4〜5 行目, 11〜13 行目の実行回数をそれぞれ評価する.

**反復の回数.** 命題 3 より, 各反復で $i$ は真に増加し, $1 \leq i \leq n$ である. $i$ の初期値は $1$ なので, 反復の回数は高々 $n - 1$ 回である. 各反復において, 4〜5 行目と 11〜13 行目を除く部分は $O(1)$ 時間なので, これらの合計は $O(n)$ 時間である.

**4〜5 行目.** $P = i + j$ とおく. $P$ の初期値は $1$ であり, 命題 3 より常に $P \leq n$ である. $P$ の変化を見ると,

* 5 行目では, $j$ が 1 増えるので $P$ が 1 増える.
* 7 行目では, $i$ が 1 増え $j$ は変わらないので $P$ が 1 増える.
* 14 行目では, $i$ が $k$ 増え $j$ が $k$ 減るので $P$ は変わらない.
* 他に $i, j$ を変更する行はない.

よって $P$ は単調非減少であり, 5 行目の実行回数は $P$ の増加量以下, すなわち高々 $n - 1$ 回である. 4 行目の判定は, 各反復で (5 行目の実行回数) $+ 1$ 回行われるので, 合計で高々 $(n - 1) + (n - 1) = 2(n - 1)$ 回である. したがって, 4〜5 行目の合計は $O(n)$ 時間である.

**11〜13 行目.** ある反復で 9 行目以降が実行されたとし, 14 行目直前の $k$ を $k$ とする. 12, 13 行目の実行回数は $k - 1$ 回, 11 行目の判定は $k$ 回であり, この反復での $i$ の増加量は $k$ に等しい. 各反復での $i$ の増加量の総和は $i$ の全体の増加量, すなわち高々 $n - 1$ なので, $k$ の総和は高々 $n - 1$ である. よって 11〜13 行目の実行回数の合計は高々 $3(n - 1)$ 回である. したがって, 11〜13 行目の合計は $O(n)$ 時間である.

以上より, 全体の計算量は $O(n)$ 時間である.

</div>

## Contents

```cpp
template<typename T>
vector<int> Z_Algorithm(const vector<T> &data)
```

* $T$ 上の列 `data` (長さ $n$) に関して, 各 $i = 0, 1, \dots, n-1$ に対し, `data` と `data` の第 $i$ 要素目以降からなる列の最長共通接頭辞の長さを求める.
* 要素同士の比較には `==` を用いるため, $T$ には `operator==` が必要である.
* **制約**: $n \geq 1$.
* **返り値**
  * 長さ $n$ の `vector<int>` 型の列 $Z$.
  * $Z_i$ は `data` と `data` の第 $i$ 要素目以降の最長共通接頭辞の長さ. 特に $Z_0 = n$.
* **計算量**: $O(n)$ 時間.

```cpp
vector<int> Z_Algorithm(const string &str)
```

* 文字列 `str` に対して, 上記と同様の列を求める.
* **制約**: $\lvert \mathrm{str} \rvert \geq 1$.
* **返り値**: 上記と同様の列 $Z$.
* **計算量**: $O(\lvert \mathrm{str} \rvert)$ 時間.
